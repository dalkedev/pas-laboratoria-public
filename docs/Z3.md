# Zadanie 3 — diagnostyka i wizyty

Zadanie korzysta ze wspólnego mechanizmu kont i sesji. Wszystkie strony diagnostyczne wymagają zalogowania przed wygenerowaniem wyników i navbara. Nazwy pozycji menu odpowiadają wykonywanym operacjom. Zgodnie z poleceniem użytkownika aplikacja nie generuje stopki ani komentarzy we własnym kodzie.

Tabela `goscieportalu` jest zawarta w `database/schema.sql`, a dla istniejącej bazy w migracji `database/z3.sql`. Każde wygenerowanie strony HTML zadania 3 zapisuje wizytę, także przed logowaniem. JavaScript uzupełnia rekord o parametry przeglądarki przez endpoint JSON związany z sesją i jednorazowym nonce. Współrzędne i linki do map nie są przechowywane w tej tabeli.

## Geolokalizacja

Helper `z3_geo()` przyjmuje wyłącznie poprawny publiczny adres IPv4 lub IPv6; adresy lokalne, prywatne i zastrzeżone zwracają status `local` bez zapytania zewnętrznego. Dostawca i adres HTTPS są stałe: `https://ipinfo.io/{IP}/geo`. Token `IPINFO_TOKEN` jest opcjonalny i należy do prywatnej konfiguracji. Sprawdzanie certyfikatu i nazwy hosta pozostaje włączone; przekierowania są wyłączone.

Pojedyncze zapytanie ma limit 1,2 s, a łączny budżet nowych zapytań w jednym żądaniu strony wynosi 4,5 s. Wielkość odpowiedzi ograniczono do 8 KiB, pola tekstowe są ograniczone i escapowane, a współrzędne sprawdzane pod względem formatu i zakresów. Błąd dostawcy, limit zapytań, brak cURL lub połączenia daje status `unavailable` i brakujące pola, zamiast wymyślonej lokalizacji.

Cache znajduje się poza katalogiem publicznym: `sys_get_temp_dir()/pas-z3-geo`, z uprawnieniami katalogu `0700` i plików `0600`. Nazwa pliku jest hashem IP. Poprawny wynik pozostaje ważny przez dobę, a niedostępność przez pięć minut. Dane dotyczą przybliżonej geolokalizacji adresu IP; aplikacja nie odczytuje GPS. Dane dostawcy mogą odpowiadać operatorowi, węzłowi VPN lub innej miejscowości niż rzeczywista lokalizacja urządzenia.

## Granice sprawdzeń

Hosting może blokować `exec`, `proc_open`, połączenia sieciowe lub DNS. Endpointy mają wówczas zwracać dostępny wynik zastępczy albo informację o niedostępności. Nie jest wymagane dokupienie SSH. Samo `phpinfo` nie dowodzi otwarcia portu, a brak odpowiedzi na loopback nie dowodzi braku usługi na innym interfejsie lub serwerze bazy danych.

Porównanie wyników między telefonem, siecią uczelnianą, operatorami komórkowymi i strefami VPN wymaga bezpośredniego uruchomienia aplikacji w tych środowiskach.
